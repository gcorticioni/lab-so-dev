# ATIVIDADE 6 — O shell como JCL moderno

# O slide da genealogia mostrou que o JCL usava comandos como
# // ASSIGN SYS004,TAPE para associar um job a um dispositivo.
# No shell moderno, qual mecanismo cumpre papel equivalente?

Resposta:
  Utiliza-se o > e o < (que cumpre o papel do assign) para gravar ou ler
    Para gravar: programa > /dev/st0
    Para ler: Programa < /dev/st0

# 1. O monitor histórico verificava a conclusão de cada job antes
#    de despachar o próximo. No make, qual mecanismo cumpre esse
#    papel? Como o make sabe que não precisa recompilar um arquivo
#    que não mudou?
    Comparando a a data e o horário do requisito e pré-requisito
      Se o arquivo de destino for mais recente do que todos os seus pré-requisitos, o make assume que o arquivo está atualizado e pula a execução daquela regra. "Nothing to be done"
      Se qualquer pré-requisito for mais recente do que o destino (ou se o destino não existir), o make dispara a receita de recompilação.
